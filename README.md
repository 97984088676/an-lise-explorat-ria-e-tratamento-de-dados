# 🌾 Análise de Dados Agronômicos e Climáticos (AgTech)

Projetos em Python para análise exploratória (EDA) e tratamento de dados aplicados ao agronegócio.

## 📌 Principais Análises
- **Clima:** Tratamento de dados, séries temporais, médias móveis e mapas de calor de temperatura.
- **Irrigação:** Monitoramento da umidade do solo com gatilhos de ativação de bombas.
- **Solos & Culturas:** Identificação do solo ideal para máxima produtividade por cultura.
- **Safras (SIGEF):** Evolução territorial de área plantada, reserva de sementes e top cultivares.

## 🛠️ Tecnologias
- **Linguagem:** Python
- **Bibliotecas:** `pandas`, `matplotlib`, `seaborn`
- **Ambiente:** Google Colab / Jupyter Notebooks
